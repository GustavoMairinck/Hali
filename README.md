# Hali

Repositório geral de estudos. Cada disciplina fica em uma pasta própria, com um site estático publicado pelo GitHub Pages.

Site: https://gustavomairinck.github.io/Hali/

| Disciplina | Pasta |
|---|---|
| Sistemas de Controle I | [`sistemas-de-controle-1/`](sistemas-de-controle-1/) |

## Adicionar uma disciplina

1. Crie uma pasta nova (ex.: `circuitos-eletricos-2/`) com um `index.html`.
2. Adicione um cartão em `index.html` (raiz) e uma linha na tabela acima.
3. Commit e push. O Pages atualiza sozinho.

Os sites são HTML, CSS e JS puros: sem build, sem dependências.
