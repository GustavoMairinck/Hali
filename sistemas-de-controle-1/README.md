# Ambiente de estudos — Sistemas de Controle I

## Como abrir

1. Descompacte a pasta.
2. Abra `index.html` no navegador (Chrome, Edge, Firefox ou Safari). Não precisa de internet nem de instalação.

O progresso (tópicos concluídos, histórico de questões, onde parou) fica salvo no navegador que você usar.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `index.html`, `assets/` | o site (HTML, CSS, JS, imagens) |
| `assets/js/data.js` | todo o conteúdo do site (gerado a partir dos arquivos .md) |
| `conteudos/` | mapa de aprendizagem, 18 tópicos, estilo do professor |
| `audios/` | 18 episódios MP3 (voz sintética pt-BR) |
| `roteiros/` | roteiro escrito de cada áudio |
| `exercicios/` | banco de questões e simulado (gabarito separado) |
| `folha-a4/` | folha de consulta em PDF e HTML + justificativa |
| `referencias/` | bibliografia |
| `relatorio.md` | relatório de conclusão e sequência de estudos |
