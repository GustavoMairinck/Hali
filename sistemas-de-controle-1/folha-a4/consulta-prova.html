0. Qual método usar? (macete)

  • “É estável?” → atalhos dos coeficientes → se inconclusivo, Routh.
  • “Faixa de K” → Routh com K → tudo > 0 → interseção.
  • “Erro em regime” → 1º checar estabilidade → tipo + GN → tabela.
  • “ζ, ωₙ, Tp, %UP…” → comparar com forma geral de 2ª ordem.
  • Gráfico → ler valor final, pico, Tp, 63% (1ª ordem).
  • “Ganhos PID” → ZN1 (curva em S, malha aberta) ou ZN2 (Ku, Pu, malha fechada).

3. Polos e zeros

  • Polo (×) = raiz do denominador → forma. Zero (○) = raiz do numerador → amplitude. Zero não define estabilidade.
  • Polo −a → Ke−at. Par −σ ± jω → Ke−σtcos(ωt−φ).
  • Resposta forçada ← polos da entrada; natural ← polos do sistema.
  • Mais à esquerda = mais rápido.

  • Coef. com sinais ≠ → instável. Falta potência de s → não estável. Todos + → inconclusivo (2ª ordem: estável).

7. Routh-Hurwitz

Linha sⁿ: an, an−2, … · Linha sⁿ⁻¹: an−1, an−3, … (completar com 0)

elem = (pivô baixo)(cima-dir) − (pivô cima)(baixo-dir)pivô baixo
nº de polos no SPD = nº de TROCAS de sinal na 1ª coluna. Sem trocas → estável.
  • Pode multiplicar/dividir uma linha por nº positivo.
  • Zero só na 1ª coluna → ε (pequeno +). Linha toda zero → polinômio auxiliar (linha de cima), derivar, usar coeficientes.
  • Faixa de K: 1ª coluna > 0 em todas as linhas; interseção (não esquecer K > 0).
  • Limite: K que zera linha s¹ = Ku. Linha s²: As² + B = 0 → ω = √(B/A); Pu = 2π/ω.

Ex.: s³+6s²+11s+6+K → Ku = 60, ω = √11, Pu = 1,89 s. Slide “1.386” = mil trezentos e oitenta e seis.

11. Pegadinhas

  • Tp usa ωd, não ωₙ. ζ = a/(2ωₙ), não a/2.
  • Routh e erro: usar malha fechada p/ estabilidade; malha aberta p/ tipo.
  • Contar trocas, não negativos.
  • Normalizar s² com coef. ≠ 1 antes de achar ζ, ωₙ.
  • Ki ≠ Ti: Ti maior = menos ação integral.
