3Laplace — propriedades

  • Linearidade: L{k·f} = k·F(s).
  • e−at·f(t) → F(s+a): troca todo s; e+at → (s−a). Sinal inverte; polo = nº do expoente. Não mexe no ω².
  • Derivada: f' → sF(s) (CI nulas); f'' → s²F(s).
  • Integral: ∫f dt → F(s)/s.
  • Valor final: f(∞) = lims→0 sF(s) — só se estável.
  • Convolução no tempo (h∗x) = produto em s (H·X).

Ex.: 5e−2tsen3t → 15(s+2)²+9 · 7e4tt⁴ → 168(s−4)⁵

4Frações parciais (volta ao tempo)

  • Uma fração por raiz. Tampar: coef. de (s−p) = resto avaliado em s=p.
  • Raiz dupla: Cs+a + D(s+a)² → Ce−at + D·t·e−at; D = tampar; C = derivar o resto e pôr s=p.
  • Δ<0: completar quadrado → (s+a)²+ω² → sen/cos com e−at.
  • Grau num ≥ grau den → dividir antes.

Ex.: s+2s(s+5) = 2/5s + 3/5s+5 → c = 2/5 + 3/5·e−5t

5Sinais de teste e impulso

Degrau = posição const. · Rampa = velocidade · Parábola = aceleração. Amplitude A → multiplica.

Resposta ao impulso: L{δ}=1 → Y = G → h(t) = L⁻¹{G(s)} = “impressão digital” do sistema. Qualquer entrada: Y = G·X.

6Controle: vocabulário

  • Controlar = variável seguir valor/trajetória desejada.
  • Referência (SP) · saída (PV) · controlador · atuador · processo · planta = atuador + processo · sensor · distúrbio.
  • MA: não mede saída (máq. de lavar). Simples, barata, não cria instabilidade; sensível a distúrbio/parâmetros.
  • MF: mede, compara, corrige. + precisão, rejeita distúrbio; + custo, manutenção, risco de instabilidade.
  • Erros de medição: grosseiro, acidental, inserção, paralaxe, zeragem.

20Ações de controle

  • On-off: 2 estados, barato, PV oscila em torno do SP; processos lentos que toleram oscilação.
  • P (presente): u = Kpe + u₀. Mais rápido, ↓erro, mas deixa off-set (se e=0, u=0). ↑Kp: ↓ erro, ↑ %UP, pode desestabilizar. Ex.: erro 20% → válvula 60% → Kp = 3.
  • I (passado): soma do erro; elimina off-set (reset); +1 no tipo. Não reduz o pico. Ki alto → oscila/instável. Não usar sozinha.
  • D (tendência): antecipa, ↓%UP; não elimina off-set (derivada de cte = 0); amplifica ruído; nunca sozinha; processos rápidos não precisam.
  • PI corrige erro · PD melhora transitório · PID os dois.
